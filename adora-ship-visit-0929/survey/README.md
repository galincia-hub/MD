## 개인정보 원칙
공개 저장소에는 실명·회사·직책과 ref 매칭표를 넣지 않는다. 해당 데이터는 Google Sheet의 `명단` 탭에만 둔다.

## 남은 연결 작업
`config.js`의 `APPS_SCRIPT_URL`은 아직 placeholder다. Google Sheet + Apps Script 웹앱 배포 후 `/exec` URL로 교체해야 실제 제출과 관리자 집계가 동작한다.
