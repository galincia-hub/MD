## 컨소시엄 지원 시스템 (consortium-support-system.html)
설계서 인계 문서 기준 8단계(계약관리·재고관리·상품자료실·판매자료배포·파트너관리·선사연동·온라인판매·선사요청) 구조의 프로토타입입니다.

- **1단계(재고 관리), 4단계(파트너 관리)만 실제 입력·저장이 되는 작동 화면**으로 완성했습니다 (상단 탭에 파란 점 표시).
  - 1단계: 항차 관리(담당 차터사 지정) · 객실 분류·실사(실사 제외 사유 등록) · 배분 현황(항차·카테고리·파트너별 배정 입력, 판매·잔여 자동계산) · 객실 배정 연동(예약 연동 배치 현황)
  - 4단계: 파트너 목록(CRUD) · 재고 배정(파트너 기준 조회) · 예약·명단 입력(승객 여권정보 포함) · 부가서비스 신청 · 정산 기초자료(CSV 내보내기) · 파트너 콘솔
- 나머지 0·2·3·5·6·7단계는 원본 프로토타입 v2의 스케치(화면 설계 예시) 그대로 남겨두었습니다.
- 항차 일정·캐빈 재고 등 마스터 데이터는 DECISIONS.md 기준 실제 값으로 교체했습니다. 담당 차터사, 개별 객실 실사(시야차단·소음 등), 하드블럭 배정·계약 조건처럼 아직 확정되지 않은 값은 "확인 필요"로 표시하고 임의로 채우지 않았습니다.
- 데이터는 브라우저 localStorage에 저장됩니다(판매관리 프로그램과 동일한 방식·한계).

## 판매관리 프로그램 (adora-md-sales-management.html)
기존 협상용 대시보드에 사이드바 "판매관리" 섹션을 추가한 확장판입니다.

- **예약/판매 관리**: 항차·캐빈타입별 예약 등록/수정/삭제, 고객·담당대리점·판매가·결제상태 관리
- **캐빈 재고 현황**: 항차별 캐빈타입별 판매 가능 재고(957실/1,914명, DECISIONS.md 기준) 대비 판매율
- **매출/정산 관리**: 항차별 총매출 - 대리점수수료(18%)·카드수수료(2.5%)·마일리지(1%)·보험료(₩20,000/인)·원가(NPD) = 순이익 자동 계산, CSV 내보내기
- **고객/영업 관리**: 담당 대리점/영업별 실적, 고객 예약 이력 조회

### 데이터 저장 방식
서버 없이 동작하는 정적 페이지 특성상 예약 데이터는 **브라우저 localStorage**에 저장됩니다.
- 같은 브라우저에서는 새로고침해도 데이터가 유지됩니다.
- 다른 기기·브라우저·시크릿 모드에서는 데이터가 공유되지 않습니다.
- "백업(JSON) 내보내기" / "백업 불러오기" 버튼으로 데이터를 파일로 저장·이동할 수 있습니다. 정기적으로 백업을 권장합니다.
- 여러 담당자가 동시에 같은 데이터를 봐야 하거나 서버/DB 기반 시스템이 필요하면 별도 논의가 필요합니다.
