2027 Adora Magic City 차터 협상용 3사 컨소시엄 미팅 대시보드.
순수 HTML + CSS + JS 단일 페이지. 빌드 도구 불필요.

  - adora-md-sales-management.html  v4 대시보드 + 판매관리 모듈 (신규)

## 판매관리 프로그램 (adora-md-sales-management.html)
기존 협상용 대시보드에 사이드바 "판매관리" 섹션을 추가한 확장판입니다.

- **예약/판매 관리**: 항차·캐빈타입별 예약 등록/수정/삭제, 고객·담당대리점·판매가·결제상태 관리
- **캐빈 재고 현황**: 항차별 캐빈타입별 판매 가능 재고(957실/1,914명, DECISIONS.md 기준) 대비 판매율
- **매출/정산 관리**: 항차별 총매출 - 대리점수수료(18%)·카드수수료(2.5%)·마일리지(1%)·보험료(₩20,000/인)·원가(NPD) = 순이익 자동 계산, CSV 내보내기
- **고객/영업 관리**: 담당 대리점/영업별 실적, 고객 예약 이력 조회

### 데이터 저장 방식
서버 없이 동작하는 정적 페이지 특성상 예약 데이터는 **브라우저 localStorage**에 저장됩니다.
- 같은 브라우저에서는 새로고침해도 데이터가 유지됩니다.
- 다른 기기·브라우저·시크릿 모드에서는 데이터가 공유되지 않습니다.
- "백업(JSON) 내보내기" / "백업 불러오기" 버튼으로 데이터를 파일로 저장·이동할 수 있습니다. 정기적으로 백업을 권장합니다.
- 여러 담당자가 동시에 같은 데이터를 봐야 하거나 서버/DB 기반 시스템이 필요하면 별도 논의가 필요합니다.

## 실행 방법
